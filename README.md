# Mon IA Montage

Petit éditeur photo/vidéo qui tourne entièrement dans le navigateur du téléphone (ffmpeg.wasm). Rien n'est envoyé sur un serveur.

Bibliothèques : [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm) (MIT, cœur FFmpeg sous GPL), [@imgly/background-removal](https://github.com/imgly/background-removal-js) chargé à la demande.
